# 🐍 Snake Game (Java Swing)

The classic **Snake** game built as a desktop app in **Java Swing**.

## ✨ Features
- Arrow-key controls with a `KeyAdapter`
- Game loop driven by `javax.swing.Timer`
- Collision detection with walls and the snake's own body
- Score increases and the snake grows with each apple
- Custom sprites for the head, body and apple

## 🛠️ Tech stack
`Java` · `Swing` · `AWT`

## 🚀 Run
```bash
cd "Sanke Game"
javac *.java
java SnakeGame
```

## 📚 What I learned
Game loops, event handling, 2D rendering with `paintComponent`, and storing game state in arrays.
